# uuid/network

[← go-core](../../READMEru.md) · [← uuid](../READMEru.md) · [English version](README.md)

Быстрые UUID для идентификаторов, которые не обязаны быть непредсказуемыми: ID запросов,
trace/span ID, ID сообщений и корреляции. Случайность берётся из глобального генератора
`math/rand/v2` (ChaCha8 на каждый поток рантайма, сид от рантайма): он потокобезопасен и
работает без блокировок.

```go
import "github.com/jwm1rr0rb10/go-core/uuid/network"
```

## API

| Функция | Описание |
|---|---|
| `NewV4() UUID` | Случайный v4 из быстрого ГПСЧ |
| `NewV7() UUID` | v7 по времени, строго монотонный, из быстрого ГПСЧ |
| `type UUID = uuid.UUID` | Тот же тип, что в корневом пакете |

## Пример

```go
func withRequestID(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		id := network.NewV4()
		w.Header().Set("X-Request-ID", id.String())
		next.ServeHTTP(w, r)
	})
}
```

| `NewV7` параллельно | ~260 (общий монотонный счётчик) |

`NewV4` масштабируется линейно по ядрам: общего состояния нет вообще.

## Безопасность

Вывод `math/rand/v2` не гарантированно непредсказуем с криптографической точки зрения. Не
используйте эти ID как токены сессий, ссылки сброса пароля и всё, что злоумышленник не
должен угадать, — для этого есть корневой пакет `uuid`.

## Миграция

- **Исправлена гонка данных**: прежняя версия делила один `*rand.ChaCha8` между горутинами
  без синхронизации, и под нагрузкой могли появляться дубликаты.
- `init()` больше не паникует — инициализации пакета нет вовсе.
- `network.UUID` теперь алиас `uuid.UUID`.
- `NewV7` теперь строго монотонный.
