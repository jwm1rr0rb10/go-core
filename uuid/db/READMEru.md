# uuid/db

[← go-core](../../READMEru.md) · [← uuid](../READMEru.md) · [English version](README.md)

Конструкторы UUID для ключей в базе данных. Тонкая обёртка над корневым пакетом
[`uuid`](../READMEru.md), которая явно говорит о назначении: криптостойкие случайные биты и
строго монотонный v7. Благодаря монотонности B-tree индекс растёт только «в конец» и не
страдает от разбиения страниц.

```go
import "github.com/jwm1rr0rb10/go-core/uuid/db"
```

## API

| Функция | Описание |
|---|---|
| `NewV7() (UUID, error)` | По времени, монотонный, crypto/rand. Рекомендуется для первичных ключей |
| `NewV4() (UUID, error)` | Случайный, crypto/rand |
| `type UUID = uuid.UUID` | Тот же тип, что в корневом пакете: `Parse`, `String`, JSON, `sql.Scanner`, `driver.Valuer` |

Ошибка всегда `nil` (crypto/rand не может завершиться ошибкой начиная с Go 1.24) и
оставлена для совместимости API. В новом коде можно сразу вызывать `uuid.NewV7()`.

## Пример

```go
id, _ := db.NewV7()
_, err := pool.Exec(ctx, "INSERT INTO orders (id, total) VALUES ($1, $2)", id, total)

var got db.UUID
err = pool.QueryRow(ctx, "SELECT id FROM orders LIMIT 1").Scan(&got)
```

## Производительность

Intel Core Ultra 5 225H, Go 1.27: `NewV7` ≈ 100–135 нс/оп в одном потоке, ≈ 350 нс/оп при
14 горутинах, 0 аллокаций. Безопасен для конкурентного вызова; уникальность и порядок внутри
горутины проверяются тестом на 8 × 100 000 ID под `-race`.

## Миграция

- Раньше `db.UUID` был отдельным типом `[16]byte`, теперь это алиас `uuid.UUID`.
  Преобразования вида `uuid.UUID(dbID)` по-прежнему компилируются, их можно убрать.
- `NewV7` теперь строго монотонный (раньше внутри миллисекунды порядок был случайным).
